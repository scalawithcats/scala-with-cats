Scala with Cats

This is the website for the book Scala with Cats. Scala with Cats has been superceded by a new book, Functional Programming Strategies.

Functional Programming Strategies updates all the material in Scala with Cats, and expands on Scala with Cats to address far more of the core concepts and techniques of functional programming. It's recommended you read Functional Programming Strategies in preference to Scala with Cats, but this site keeps around Scala with Cats for the sake of posterity.

My thanks to everyone who supported Scala with Cats, and to those who are supporting its evolution into Functional Programming Strategies. It's been a long journey, but hopefully you'll find it has been worthwhile.

Noel
